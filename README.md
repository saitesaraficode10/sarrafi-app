# صرافی آنلاین (Sarrafi App)

پلتفرم کامل صرافی با پشتیبانی از دلار، درام، ریال ایران، تتر و روبل.

## پیش‌نیاز
- Node.js 18+ (ترجیحاً 20+)
- npm

## نصب و اجرا

1. وارد پوشه شوید:
```bash
cd sarrafi-app
```

2. نصب پکیج‌ها:
```bash
npm install
```

3. فایل `.env` را ویرایش کنید و رمزهای ادمین را عوض کنید.

4. ساخت دیتابیس:
```bash
node utils/init-db.js
```

5. اجرا:
```bash
npm start
```

سایت: http://localhost:3000

ادمین: http://localhost:3000/admin/login
(یوزر و پس از فایل .env)

## امکانات
- ثبت‌نام با آپلود پاسپورت
- کد یکتای کاربر
- نرخ لحظه‌ای از API + تغییر دستی
- سفارش + انتخاب بانک + نمایش کارت/شبا
- آپلود رسید
- اعلام زمان مراجعه به دفتر توسط ادمین
- داشبورد ادمین با جستجوی کد کاربر
- ۴ زبان: فارسی، انگلیسی، روسی، ارمنی
